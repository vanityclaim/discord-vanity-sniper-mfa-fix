## Installation

Install the required dependencies:

```bash
npm i
```

## Configuration

Open `config.json` and fill in the required values.

```json
{
  "token": "YOUR_TOKEN",
  "guildId": "YOUR_GUILD_ID"
}
```

## Usage

After configuring `config.json`, start the sniper:

```bash
node sniper.js
```

That's it
